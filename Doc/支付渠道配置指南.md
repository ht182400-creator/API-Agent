#### 3.3 SDK 配置示例代码

```python
from alipay.aop.api.AlipayClientConfig import AlipayClientConfig
from alipay.aop.api.DefaultAlipayClient import DefaultAlipayClient

# 1. 创建配置对象
alipay_client_config = AlipayClientConfig()

# 2. 设置配置参数
alipay_client_config.server_url = 'https://openapi.alipaydev.com/gateway.do'  # 或生产网关

alipay_client_config.app_private_key = 'MIIEvQIBADANB...'  # 应用私钥（PKCS8格式）
alipay_client_config.alipay_public_key = 'MIIBIjANB...'  # 支付宝公钥

# 3. 创建客户端
client = DefaultAlipayClient(alipay_client_config)
```

#### 3.4 项目中的配置方式

本项目在 `src/config/settings.py` 中配置：


### 4. RSA2 密钥生成与配置

#### 4.1 生成密钥对（Linux/Mac）

```bash
# 1. 生成 RSA2 私钥
openssl genrsa -out app_private_key.pem 2048

# 2. 保留 PKCS1 格式私钥（SDK 要求）
# 注意：alipay-sdk-python 使用 rsa 库的 load_pkcs1 方法加载私钥
# 因此必须使用 PKCS1 格式（-----BEGIN RSA PRIVATE KEY-----），不是 PKCS8 格式
cp app_private_key.pem app_private_key_pkcs1.pem

# 3. 生成公钥
openssl rsa -in app_private_key.pem -pubout -out app_public_key.pem

# 4. 查看密钥内容
cat app_private_key_pkcs1.pem    # 应用私钥（PKCS1 格式）
cat app_public_key.pem           # 应用公钥（需提交给支付宝）
```

#### 4.2 Windows 系统生成

Windows 用户建议使用支付宝提供的密钥生成工具：
- 下载地址：https://opendocs.alipay.com/open/291/106097/
- 工具可以同时生成公钥私钥对

**然后使用 Python 脚本转换为 PKCS1 格式**（参考项目中的 `convert_key.py`）：
```python
from cryptography.hazmat.primitives import serialization
from cryptography.hazmat.backends import default_backend

with open('keys/alipay_private_key.pem', 'r') as f:
    pkcs8_key = f.read()

private_key = serialization.load_pem_private_key(
    pkcs8_key.encode(), password=None, backend=default_backend()
)

pkcs1_pem = private_key.private_bytes(
    encoding=serialization.Encoding.PEM,
    format=serialization.PrivateFormat.TraditionalOpenSSL,
    encryption_algorithm=serialization.NoEncryption()
)

with open('keys/alipay_private_key_pkcs1.pem', 'wb') as f:
    f.write(pkcs1_pem)
```

#### 4.3 提交公钥

1. 登录蚂蚁金服开放平台：https://open.alipay.com/
2. 进入「应用详情」→「开发设置」→「接口加签方式」
3. 选择「RSA2(SHA256)」签名算法
4. 粘贴应用公钥内容，保存
5. 平台会生成「支付宝公钥」，复制保存

> ⚠️ **重要**：alipay-sdk-python 需要 **PKCS1 格式** 私钥，不是 PKCS8 格式！常见错误 `Incorrect padding` 通常是私钥格式不正确导致的。

### 5. 常用支付接口调用示例

#### 5.1 PC 端支付（当面付）

```python
from alipay.aop.api.request.AlipayTradePagePayRequest import AlipayTradePagePayRequest
from alipay.aop.api.domain.AlipayTradePagePayModel import AlipayTradePagePayModel

# 创建请求模型
model = AlipayTradePagePayModel()
model.out_trade_no = "202601011200001"  # 商户订单号
model.total_amount = "100.00"            # 订单金额
model.subject = "账户充值"                # 订单标题
model.product_code = "FAST_INSTANT_TRADE_PAY"  # 产品码

# 创建请求
request = AlipayTradePagePayRequest(biz_model=model)
request.return_url = "https://yourdomain.com/recharge"  # 同步跳转地址
request.notify_url = "https://yourdomain.com/api/v1/payments/alipay/callback"  # 异步通知

# 执行请求，获取支付表单或跳转 URL
response = client.page_execute(request, http_method="GET")
# response 是支付页面的 URL，可用于重定向或生成二维码
```

#### 5.2 App 支付

```python
from alipay.aop.api.request.AlipayTradeAppPayRequest import AlipayTradeAppPayRequest
from alipay.aop.api.domain.AlipayTradeAppPayModel import AlipayTradeAppPayModel

model.out_trade_no = "202601011200001"

response = client.sdk_execute(request)
# 将 response 发送给 App，App 使用 Alipay SDK 唤起支付
```

#### 5.3 交易查询


#### 5. 配置项说明

## 回调通知配置

### 回调地址要求

1. **公网可访问**：第三方支付平台需要能访问到你的回调地址
2. **使用 HTTPS**：强烈建议使用 HTTPS
3. **保持幂等**：回调接口需要处理重复通知

### 回调验证

所有回调都需要验证签名：

#### 支付宝回调验证（新版 SDK）

```python
from alipay.aop.api.util.SignatureVerify import verify

# 获取 POST 请求中的签名和参数
signature = request.POST.get('sign')
sign_type = request.POST.get('sign_type', 'RSA2')

# 构建待验签的字符串（按字典序排序，拼接 key=value）
# 排除 sign 和 sign_type 参数
params_to_sign = {k: v for k, v in request.POST.items() 
                  if k not in ('sign', 'sign_type')}
sign_content = '&'.join(f'{k}={v}' for k, v in sorted(params_to_sign.items()))

# 验签（使用支付宝公钥）
is_valid = verify(sign_content, signature, alipay_public_key, sign_type)
if is_valid:
    # 验签通过，处理订单
    trade_status = request.POST.get('trade_status')
    out_trade_no = request.POST.get('out_trade_no')
    # ... 业务处理
```

#### 微信支付回调验证

```python
from wechatpayv3 import WeChatPay

wxpay = WeChatPay(...)
if wxpay.verify(request_params, signature):
    # 验证通过，处理订单
```

### 回调处理建议

1. 返回成功响应后再处理业务逻辑
2. 使用幂等键防止重复处理
3. 记录回调日志便于排查

1. **不要硬编码**：将密钥存储在配置文件或环境变量

| 环境 | 说明 |

## 常见问题

### Q1: 沙箱环境测试正常，但切换到生产环境失败

**检查项**：
1. 确认 AppID/MchID 是否正确
2. 确认公钥/密钥是否为生产环境生成
3. 确认 notify_url 是否为 HTTPS

### Q2: 回调通知接收不到

**检查项**：
1. 确认 notify_url 公网可访问
2. 检查防火墙/安全组设置
3. 查看服务端日志

### Q3: 签名验证失败

**检查项**：
1. 确认密钥格式正确（PKCS8）
2. 确认使用正确的支付宝公钥（不是应用公钥）
3. 检查编码格式（UTF-8）

### Q4: SDK 导入报错 `ModuleNotFoundError: No module named 'alipay'`

**原因**：使用了旧版的第三方 SDK（如 `alipay` 包）

**解决方案**：
```bash
# 卸载旧版 SDK
pip uninstall alipay

# 安装官方新版 SDK
pip install alipay-sdk-python
```

### Q5: request sign failed 签名失败

**可能原因**：
1. 私钥格式不正确（需要 PKCS8 格式）
2. 网关地址配置错误（沙箱/生产环境混淆）
3. 网络问题无法连接支付宝服务器

**解决方案**：
1. 检查私钥是否为 PKCS8 格式（以 `-----BEGIN PRIVATE KEY-----` 开头）
2. 确认环境配置：`ALIPAY_SANDBOX=true` 使用沙箱网关
3. 测试网络：`curl https://openapi.alipay.com/gateway.do`
4. 查看详细日志获取具体错误信息

### Q6: 如何确认密钥格式？

**PKCS1 格式**（旧格式，需要转换）：
```
-----BEGIN RSA PRIVATE KEY-----
MIIEpAIBAAKCAQEA...
-----END RSA PRIVATE KEY-----
```

**PKCS8 格式**（支付宝要求）：
```
-----BEGIN PRIVATE KEY-----
MIIEvQIBADANB...
-----END PRIVATE KEY-----
```

转换命令：
```bash
openssl pkcs8 -topk8 -inform PEM -outform PEM -in app_private_key.pem -out app_private_key_pkcs8.pem -nocrypt
```

### Q7: 支付宝跳转支付（return_url）显示"支付记录不存在"

**问题描述**：
使用支付宝跳转支付后，从支付宝返回页面显示"支付记录不存在"。

**原因分析**：
- 支付宝 return_url 携带的参数是 `out_trade_no`（商户订单号）
- 数据库中 `out_trade_no` 对应的是 `order_no` 字段，不是 `payment_no` 字段
- 原 API 只支持用 `payment_no` 查询，导致用 `out_trade_no` 查询时找不到记录

**解决方案**：
- V7.4 版本已修复，API 同时支持 `payment_no` 和 `order_no` 查询
- 如果使用的是旧版本，需要升级或手动修改 `api-platform/src/api/v1/payment.py` 中的 `query_payment_status` 接口

**修复代码参考**（V7.4）：
```python
@router.get("/status/{payment_no}", response_model=BaseResponse[PaymentStatusResponse])
async def query_payment_status(
    payment_no: str,
    db: AsyncSession = Depends(get_db),
):
    service = PaymentService(db)
    
    # 【V7.4 修复】先尝试用 payment_no 查询，如果找不到再尝试 order_no
    payment = await service.query_payment(payment_no)
    
    if not payment:
        # 尝试用 order_no 查询（支付宝 out_trade_no）
        payment = await service.query_payment_by_order(payment_no)
    
    if not payment:
        from src.core.exceptions import NotFoundError
        raise NotFoundError("支付记录不存在")
    
    # 如果支付成功，自动更新用户余额
    if payment.status in ("paid", "completed"):
        await service.update_user_balance_after_payment(payment.payment_no)
    
    # ... 其余代码
```

# 支付宝回调签名验证问题解决记录

## 问题描述

- **发生时间**: 2026-05-08 09:51
- **现象**: 支付宝扫码付款成功，支付宝回调也返回 200 OK，但商户页面一直停留在二维码扫描阶段
- **错误表现**: 支付宝返回 `{"success": false, "message": ""}`

## 根本原因

支付宝回调处理函数中的签名验证失败：

```
File "d:\Work_Area\AI\API-Agent\api-platform\src\api\v1\payment.py", line 654, in alipay_callback
    is_valid = verify_with_rsa(settings.get_alipay_public_key(), sign_content, signature)
...
AssertionError: assert hasattr(message, "read") and hasattr(message.read, "__call__")
```

`verify_with_rsa()` 函数（来自 alipay SDK）期望 message 参数是**有 `read()` 方法的对象**（如 BytesIO），而不是普通字符串。

## 修复方案

**文件**: `src/api/v1/payment.py`

**修改位置**: 约第 654 行 `alipay_callback` 函数内

**修改前**:
```python
sign_content = "&".join(sign_parts)
is_valid = verify_with_rsa(settings.get_alipay_public_key(), sign_content, signature)
```

**修改后**:
```python
sign_content = "&".join(sign_parts)

# 验证签名：verify_with_rsa 需要 message 是有 read() 方法的对象
from io import BytesIO
message_stream = BytesIO(sign_content.encode('utf-8'))
is_valid = verify_with_rsa(settings.get_alipay_public_key(), message_stream, signature)
```

## 解决步骤

1. 查看错误日志 `logs/errors_20260508.log` 发现 `AssertionError`
2. 检查 `payment.py` 中的 `alipay_callback` 函数
3. 定位到签名验证代码，发现需要将字符串转换为 BytesIO
4. 停止服务、清除 `__pycache__` 缓存
5. 重启服务验证
